API Reference
=============

Complete API documentation for all modules, classes, and functions in SolarWindPy.

Every page under this reference is generated by ``sphinx.ext.autosummary`` from
the package source. Each subpackage below is listed once with ``:recursive:``,
so every module it contains is documented without being listed here by hand.

.. Every table on this page uses fully qualified names and no currentmodule:
   autosummary rejects a name that repeats the current module. The package
   module itself is documented last on the page for the same reason, because
   automodule sets the current module for everything after it.
