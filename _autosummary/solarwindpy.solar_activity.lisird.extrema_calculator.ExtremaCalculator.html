class ExtremaCalculator(name, activity_index, threshold=None, window=600)[source]

Bases: object

Determine extrema in an activity index time series.

The calculator smooths the input series with a rolling mean and finds local minima and maxima based on a threshold value.

set_threshold(threshold)[source]

Set the threshold that separates maxima from minima.

Parameters:
thresholdfloat, callable(), or None

A number is used as is. Any callable (a def or lambda, a numpy function such as numpy.nanmedian(), or a functools.partial) is called with data and its result used. None selects the value tabulated for name; when name is not tabulated it selects numpy.nanmedian(), so the threshold is the median of data.
