Make a stacked fit, residual plot.

Parameters:

If True, add fit annotation to axis.

If not None, (fit, resid) axis pair to plot the (raw, used, fit) and residual on, respectively. Otherwise, use GridSpec to build a pair of axes where the raw_used_fit axis is 3 times the resid_axis. Additionally, if fit_resid_axes is None, the hax and rax will share an x-axis and hax’s x-ticks and label will be set invisible.

Any valid figsize for matplotlib.pyplot.figure(). This code was developed with default size 6x4 and this size helps accomodate annotation. So we persist it here.
