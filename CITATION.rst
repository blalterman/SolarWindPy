How to cite
===========

If SolarWindPy contributes to published work, please cite it.

SolarWindPy is archived on Zenodo under the DOI
`10.5281/zenodo.17042839 <https://doi.org/10.5281/zenodo.17042839>`_.

This is Zenodo's all-versions (concept) DOI. It identifies every SolarWindPy
release and resolves to the most recent one. Each release also has its own
version DOI on the Zenodo record, but please cite the all-versions DOI, so that
every citation of SolarWindPy is counted in one place, and give the version you
used in your text.

To cite SolarWindPy, use the all-versions DOI:

    Alterman, B. L. SolarWindPy. Zenodo. doi:10.5281/zenodo.17042839

BibTeX:

.. code-block:: bibtex

   @software{Alterman_SolarWindPy,
     author    = {Alterman, B. L.},
     title     = {SolarWindPy},
     publisher = {Zenodo},
     doi       = {10.5281/zenodo.17042839},
     url       = {https://doi.org/10.5281/zenodo.17042839}
   }
